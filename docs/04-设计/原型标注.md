# 原型标注

当前原型已由 `src/App.vue` 实现为可运行前端，不再单独生成静态 HTML（HyperText Markup Language，超文本标记语言）原型。本文件对现有页面进行字段、规则和交互标注。

## 1. 全局标注

- 左侧导航按角色分组：员工端、项目管理端、财务端。
- 顶部显示当前角色和账号，例如 `employee01`、`admin01`、`finance01`、`superadmin01`。
- 当前角色切换仅用于本地演示，不等同于生产登录。
- 金额展示为人民币，生产建议统一使用分为最小存储单位，避免浮点误差。

## 2. 项目列表

| 字段 / 控件 | 中文说明 | 规则 |
|---|---|---|
| 项目状态 | 未开放、未满额、已满额、已截止、已中断、已完结 | 只有 `未满额` 可以进入认购 |
| 剩余可认购金额 | 当前还能由员工认购的金额 | 不得小于 0 |
| 认购进度 | 已认购金额 / 项目开放金额 | 满额后应更新为 100% |
| 截止时间 | 员工认购截止点 | 超时后不可继续认购 |

## 3. 项目详情 / 认购

| 字段 / 控件 | 中文说明 | 规则 |
|---|---|---|
| 协议勾选 | 用户协议、安全协议、风险提示 | 三项都确认后才允许提交 |
| 认购金额 | 员工本次认购金额 | 不低于规则最低金额，不超过剩余额度 |
| 提交认购 | 创建认购记录 | 必须携带 `idempotencyKey` |

## 4. 认购规则配置

| 字段 / 控件 | 中文说明 | 规则 |
|---|---|---|
| 规则名称 | 项目认购规则名称 | 必填 |
| 总开放认购金额 | 本项目开放给员工和公司的认购总额 | 必须大于 0 |
| 公司固定认购金额 | 公司预先承担或固定认购部分 | 不得超过总开放金额 |
| 最低认购金额 | 员工单次最低提交金额 | 必须大于 0 |
| 最低参与人数 | 项目期望参与人数 | 必须大于 0 |
| 允许多次认购 | 员工是否可重复提交 | 生产需考虑单人上限 |
| 公司兜底 | 截止未满额时是否允许公司接管 | 需管理层确认规则 |

## 5. 支付复核

| 字段 / 控件 | 中文说明 | 规则 |
|---|---|---|
| OCR 识别金额 | 从支付截图识别出的金额 | 与认购金额不一致时进入待复核 |
| 通过 | 财务确认到账一致 | 更新为已缴款 |
| 驳回 | 财务确认凭证无效 | 更新为复核驳回并记录原因 |
| 部分缴款 | 财务确认到账不足 | 更新为部分缴款，后续需补缴或退款策略 |

## 6. 项目结算

- 成本金额、销售金额、利润金额由项目数据计算。
- 员工认购、公司固定认购、公司强制接管金额需分开展示。
- 发票 OCR 当前为模拟交互，生产需接真实发票识别和验真。

## 7. 审计与风险

- 审计日志必须展示操作时间、操作人、角色、动作、对象和结果。
- 风险事件至少记录中断原因、OCR 异常、超时未缴款和强制接管。
