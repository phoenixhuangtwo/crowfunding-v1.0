- 实现关联：`src/App.vue`

## 一、需求背景与目标

项目管理表格字段较多，管理员横向查看金额、利润和结算信息时，“操作”列会离开当前视窗，需要滚动到最右侧才能执行支付复核、结算、开放、终止或强制接管。

本次变更将“操作”列固定在表格当前视窗右侧，让管理员在查看任意横向字段时都能直接操作当前行。

## 二、目标用户与使用场景

- 目标角色：管理员、公司超级管理员及当前可进入项目管理页的用户。
- 使用入口：项目管理页项目表格。
- 典型场景：横向滚动查看项目金额或结算字段时，操作列始终在右侧可见。

## 三、用户可见方案

- “操作”列表头和每行按钮固定在表格右侧。
- 横向滚动只移动其他业务字段，操作列位置不变。
- 所有按钮的文案、启停状态和点击行为保持不变。

## 四、边界与非目标

- 不调整其他列顺序、宽度或字段内容。
- 不修改操作按钮权限、状态判断或业务接口。
- 不固定“规则配置”等其他列。

## 五、验收标准

1. 项目管理表格位于最左、任意中间位置和最右滚动位置时，“操作”列均在表格右侧可见。
2. 表头与数据行对齐，固定列不会遮挡或错位。
3. 现有操作按钮功能与禁用状态不变。
4. TypeScript（类型语言）与 Vue（前端框架）生产构建通过。

## 六、方案与取舍

使用 Element Plus（前端组件库）表格列原生右侧固定能力，只修改目标列配置。该方式差异最小，并沿用组件自身的滚动同步和阴影处理。

## 七、章节变更草案

### 《01-内部资金认购平台》4.5 项目管理
