- 实现关联：`src/App.vue`

## 一、需求背景与目标

创建认购规则时，两个系统推导金额显示在其输入字段之前，不便于用户理解数值来源。本次将输入字段放在对应推导结果之前，使填写顺序与计算依赖一致。

## 二、目标用户与使用场景

- 目标角色：可进入认购规则配置页并创建规则的用户。
- 使用入口：认购规则配置页的“创建认购规则”弹窗。
- 典型场景：先填写公司固定认购金额和开放参与人数，再查看系统推导出的开放认购金额和单次认购最低金额。

## 三、用户可见方案

相关字段按以下顺序展示：

1. 公司固定认购金额。
2. 开放认购金额。
3. 开放参与人数。
4. 单次认购最低金额。

## 四、边界与非目标

- 不修改开放认购金额和单次认购最低金额的计算公式。
- 不修改字段校验、默认值、保存接口或数据结构。
- 不调整弹窗内其他字段的顺序和交互。

## 五、验收标准

1. 创建认购规则弹窗中四个字段严格按确认顺序展示。
2. 公司固定认购金额仍位于其推导结果“开放认购金额”之前。
3. 开放参与人数仍位于其推导结果“单次认购最低金额”之前。
4. 现有测试与生产构建通过。

## 六、方案与取舍

仅调整 Vue（前端框架）模板中四个 `el-form-item`（表单项）的页面结构顺序，保留各表单项内部绑定、计算属性与提示文案。

## 七、章节变更草案

### 《01-内部资金认购平台》4.6 认购规则配置
