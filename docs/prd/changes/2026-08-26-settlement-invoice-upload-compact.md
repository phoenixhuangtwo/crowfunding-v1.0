# 增量 PRD：项目结算发票上传入口紧凑化

- 状态：merged
- 日期：2026-08-26
- 发起人：用户确认需求 / Codex 实现
- 需求落点：增强现有模块
- 涉及章节：01-内部资金认购平台 §4.9、§9、§10
- 实现关联：`src/styles.css`

## 一、需求背景与目标

项目结算页的发票拖拽上传区高度较大，在已经展示项目数据、发票预览和结算明细时占用过多纵向空间。此次缩小上传入口，让财务更快看到上传结果和下方明细。

## 二、目标用户与使用场景

- 目标用户：财务人员。
- 使用入口：项目结算页确认发起结算后的发票上传区域。
- 触发场景：选择或拖拽发票图片、重新选择图片。
- 异常与权限：沿用现有上传校验和页面权限。

## 三、用户可见方案

- 上传区保持整行宽度，但减少上下留白和图标尺寸。
- 拖拽、点击选择和提示文字保持不变。
- 仅影响项目结算的发票上传区，不影响支付截图和收款码上传组件。

## 四、边界与非目标

- 不改变支持格式、大小限制、实际图片预览和 OCR（光学字符识别）逻辑。
- 不改变其他页面的上传组件。
- 不新增接口、状态、权限或持久化能力。

## 五、验收标准

1. 发票上传区高度由约 140px 缩小到约 72px。
2. 提示文字和上传图标仍完整可见。
3. 整个区域仍支持点击选择和拖拽文件。
4. 实际发票预览、文件名和 OCR 金额继续正常展示。

## 六、方案与取舍

保留横向满宽点击区域，仅压缩纵向尺寸，兼顾操作命中面积和页面信息密度；不改成小按钮，避免削弱拖拽能力。

## 七、章节变更草案

项目结算发票上传入口采用紧凑高度，减少上下留白和图标尺寸，同时保持整行可点击、可拖拽以及原提示文字。

## 八、影响面清单

- 权限点：不涉及。
- 菜单：不涉及。
- DataScope（数据范围）：不涉及。
- 状态口径：不涉及。
- 通知：不涉及。
- 搜索：不涉及。
- 后台任务：不涉及。
- AI 边界：不涉及。
- 多端：当前 Web 页面生效；无独立移动端实现。

## 九、开放问题

无。
