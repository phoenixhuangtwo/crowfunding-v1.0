## 一、需求背景与目标

项目管理页当前提供“同步采购系统（MCP）”入口，但点击后只返回本地模拟结果，管理员无法确认真实采购系统是否存在可用于后续认购管理的订单数据。

本次变更目标是让管理员在现有入口中发起一次真实、只读的采购订单分页拉取，并获得清晰的成功或失败反馈。外部系统异常不得覆盖现有有效项目，也不得阻断本地认购核心流程。

## 二、目标用户与使用场景

- 目标角色：管理员、公司超级管理员。
- 使用入口：项目管理页右上角“同步采购系统（MCP）”。
- 触发时机：管理员需要确认采购系统中当前第一页采购订单数据是否可用时。
- 前置条件：本地后端已配置有效的采购系统认证信息，且能访问采购系统。
- 典型路径：点击同步按钮 → 阅读风险提示并确认 → 等待拉取 → 查看本次获取条数与采购系统总条数。
- 异常场景：认证缺失、令牌失效、网络失败、采购系统返回异常时，页面显示明确失败原因，现有项目数据保持不变。
- 权限不足：沿用当前项目管理页的角色可见性；本期不新增生产级接口鉴权。

## 三、用户可见方案

1. 管理员点击“同步采购系统（MCP）”后，系统保留现有二次确认，明确本次操作只读取采购订单，不覆盖已有有效项目。
2. 管理员确认后，按钮对应流程进入等待状态，系统通过本地服务访问真实采购系统，认证信息不下发到浏览器。
3. 拉取成功后，页面提示本次获取条数和采购系统返回的总条数，并写入一条同步审计记录。
4. 拉取失败时，页面显示可理解的错误提示；失败请求不更新现有项目、认购、规则或结算数据。
5. 本次拉取到的采购订单不自动转换为内部认购项目，避免在字段口径和状态映射尚未确认前污染本地项目数据。

## 四、边界与非目标

- 本期只读取采购订单分页数据，不创建、编辑或删除采购系统订单。
- 本期固定使用已确认的第一页、每页 10 条及现有筛选条件，不新增页面筛选配置。
- 本期不把采购订单自动写入本地 `Project`（项目）数据，也不做去重、增量更新或状态映射。
- 本期不新增定时同步、重试队列、外部通知、全局搜索或 AI（人工智能）决策。
- 本期不新增生产级登录、接口级 RBAC（基于角色的访问控制）或密钥管理平台；认证信息仅保存在本地、被版本控制忽略的环境配置中。
- 外部采购系统属于可选集成层；其不可用不得阻断核心认购流程。

## 五、验收标准

1. 已配置有效认证信息时，管理员确认同步后可看到“本次获取 10 条、共 N 条”一类包含本次数量与总量的成功反馈。
2. 浏览器请求、前端源代码和前端构建产物中不出现采购系统认证令牌。
3. 未配置认证信息时，同步请求返回明确的配置缺失提示，页面不显示虚假的同步成功。
4. 采购系统返回非成功状态、业务错误或无法解析的数据结构时，同步失败并显示明确提示。
5. 同步成功生成审计记录；审计内容只记录拉取数量与总量，不记录认证令牌或完整订单明细。
6. 无论成功或失败，现有本地项目列表及其他业务数据均不被本次只读拉取覆盖。
7. 自动化测试覆盖成功、认证缺失和上游失败场景，项目构建与现有冒烟测试通过。

## 六、方案与取舍

采用“浏览器调用本地 API（应用程序接口），本地后端代理访问采购系统”的方式，而不让浏览器直接访问外部接口。这样可以避免认证令牌暴露，也能统一处理上游错误和审计。

本次不立即导入本地项目。采购订单字段虽然包含项目名称、售价、成交价、成本价和采购状态，但尚未确认内部项目状态、认购金额、截止时间及去重键的业务映射；先验证稳定拉取，再单独评审数据转换规则，风险更低。

该方案不推翻“核心认购流程不得依赖可选外部服务”的设计原则：采购系统调用失败时仅影响本次同步反馈，本地核心认购能力继续可用。

## 七、章节变更草案

### 《01-内部资金认购平台》4.5 项目管理

- 管理员可在项目管理页触发真实采购订单分页拉取。
- 拉取前需要二次确认；成功后展示本次获取条数和采购系统总条数，并记录审计。
- 认证缺失、令牌失效、网络或上游业务异常时，系统明确提示失败，且不覆盖已有有效项目。
- 当前真实拉取只用于验证外部订单可读性，不自动转换为内部认购项目；字段与状态映射需通过后续增量 PRD 明确。

### 《01-内部资金认购平台》6 API 与实现锚点

- `POST /api/mcp/sync`：由“MCP 同步模拟”调整为“通过本地后端代理只读拉取采购订单分页数据并返回数量摘要”。

### 《01-内部资金认购平台》7 边界与约束

- 外部采购系统继续属于可独立降级的可选集成；同步失败不得影响本地项目、认购、支付与结算核心流程。
- 采购系统认证信息只允许保存在服务端环境配置中，不得下发或写入前端构建产物。

- 正式生产环境的令牌轮换、密钥托管和接口级权限校验：待生产化阶段确认，本期仅采用本地环境配置。
