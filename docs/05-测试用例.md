## 5. 当前可执行验证

当前 `tests/procurement-sync.test.ts` 覆盖采购分页查询、认证缺失、认证失效和上游业务错误；`tests/smoke.mjs` 覆盖真实同步路由、健康检查、状态读取、规则查询、创建认购幂等和数据恢复保护。建议在每次提交前执行：

```bash
npm run build
npm test
```
