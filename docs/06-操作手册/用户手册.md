# 用户手册

## 1. 查看项目并提交认购

### 场景

员工希望参与内部资金认购项目。

### 前置条件

- 当前角色为员工。
- 项目状态为 `未满额`。
- 项目存在可认购余额。

### 操作步骤

1. 打开本地前端地址 `http://127.0.0.1:5174/`。
2. 在角色区域选择员工账号，例如 `employee01`。
3. 进入“项目列表”，按状态或关键字筛选项目。
4. 点击项目进入详情页，查看项目总额、剩余额度、截止时间和风险提示。
5. 勾选用户协议、安全协议、风险提示。
6. 输入认购金额并提交。

### 预期结果

系统生成认购记录，页面可在“我的认购”中看到该项目和支付状态。

### 常见问题

- 如果提交按钮不可用，检查项目是否为 `未满额`，以及三项协议是否全部确认。
- 如果提示金额超过剩余额度，降低认购金额后重试。

## 2. 上传支付凭证并触发 OCR

### 场景

员工已线下转账，需要提交支付截图。

### 前置条件

- 已存在未缴款认购记录。

### 操作步骤

1. 进入“我的认购”。
2. 找到未缴款记录，点击支付或上传凭证入口。
3. 上传或模拟上传支付截图。
4. 触发 OCR（Optical Character Recognition，光学字符识别）校验。

### 预期结果

OCR 通过时状态更新为已缴款；金额不一致或识别失败时进入待复核。

## 3. 确认收款

### 场景

项目结算后，员工需要确认已收到款项。

### 前置条件

- 认购记录状态为待确认收款。

### 操作步骤

1. 进入“我的认购”。
2. 找到待确认收款记录。
3. 点击确认收款。

### 预期结果

认购记录状态更新为已收款，并写入审计日志。
