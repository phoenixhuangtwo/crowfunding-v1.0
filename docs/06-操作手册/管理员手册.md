# 管理员手册

## 1. 同步项目

### 场景

管理员需要把外部项目同步到认购平台。

### 前置条件

- 当前角色为管理员。
- 本地 API 已启动。

### 操作步骤

1. 打开“项目管理”。
2. 点击 MCP（Model Context Protocol，模型上下文协议）同步入口。
3. 等待页面提示同步成功。
4. 查看项目列表是否出现或更新同步项目。

### 预期结果

项目列表更新，同步动作写入审计日志。

## 2. 配置认购规则

### 场景

项目开放前，需要配置总开放金额、最低认购额、参与人数、收款码和是否允许公司兜底。

### 前置条件

- 项目已存在。
- 收款码已启用。

### 操作步骤

1. 打开“认购规则配置”。
2. 点击创建规则。
3. 选择项目并填写规则名称。
4. 填写总开放认购金额、公司固定认购金额、最低认购金额和最低参与人数。
5. 选择启用收款码。
6. 设置是否允许多次认购和公司兜底。
7. 保存并启用规则。

### 预期结果

规则出现在列表中，状态为已启用，可用于开放项目。

## 3. 开放或中断项目

### 场景

管理员需要将项目开放给员工认购，或因供应商 / 风险原因中断认购。

### 前置条件

- 开放项目：项目为未开放且存在已启用规则。
- 中断项目：必须能说明中断原因。

### 操作步骤

1. 打开“项目管理”。
2. 找到目标项目。
3. 开放项目时选择已启用规则并确认。
4. 中断项目时填写中断原因并确认。

### 预期结果

开放后项目状态变为未满额；中断后项目状态变为已中断，并生成风险事件和审计日志。

## 4. 财务复核支付

### 场景

财务需要处理 OCR 异常或待复核的支付记录。

### 前置条件

- 当前角色为财务。
- 存在待复核支付记录。

### 操作步骤

1. 打开“支付复核”。
2. 查看认购金额、OCR 识别金额、上传时间和凭证信息。
3. 选择通过、驳回或部分缴款。
4. 驳回或部分缴款时填写原因。

### 预期结果

认购支付状态更新，复核人和复核时间记录完整，审计日志可追溯。

## 5. 公司兜底与强制接管

### 场景

项目截止未满额，需要公司接管剩余可认购金额。

### 前置条件

- 当前角色为公司超级管理员。
- 项目存在剩余额度。
- 兜底规则和收益归属已获得管理层确认。

### 操作步骤

1. 打开公司兜底或项目管理入口。
2. 找到目标项目。
3. 点击强制接管。
4. 确认接管金额和影响。

### 预期结果

项目剩余额度扣减，公司强制接管金额增加，动作写入审计日志。
